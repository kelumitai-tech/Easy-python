💡 ස්මාර්ට් කේතීකරණ රහස් (Smart Coding Tricks)

පයිතන් කේතීකරණයේදී ඔබව ප්‍රවීණයෙකු (Expert) කරන සුවිශේෂී රහස් කිහිපයක් පහත දැක්වේ:

🚀 Secret 1: කෝලන් (:) සහ Indentation
ඔබේ කේතයේ If, For, While, Def වැනි පාලන ව්‍යුහයන් (Control Structures) ලියන සෑම විටම පේළිය අවසානයේ : යෙදීමට අමතක නොකරන්න. ඉන්පසු එන පේළිය අනිවාර්යයෙන්ම හිස්තැන් (Space/Tab) තබා ආරම්භ කළ යුතුය.
🚀 Secret 2: දත්ත ව්‍යුහ ක්ෂණිකව හඳුනාගැනීම
වරහන් වර්ගය දුටු පමණින් දත්ත ව්‍යුහය හඳුනාගන්න:
  • [ ] කො‍ටු වරහන් = List (ඕනෑම විටක වෙනස් කළ හැක)
  • ( ) සාමාන්‍ය වරහන් = Tuple (වරක් හැදූ පසු වෙනස් කළ නොහැක)
  • { } සඟල වරහන් = Dictionary (Key-Value යුගල ලෙස ගබඩා වේ)
🚀 Secret 3: මනසින් කේතය ධාවනය කිරීම (Dry Run)
ඔබේ කේතයේ දෝෂයක් (Bug) ඇතිවිට, පරිගණකයක් මෙන් සිතා පේළියෙන් පේළිය කේතය කියවන්න. විචල්‍යයක අගය වෙනස් වන සෑම අවස්ථාවක්ම කඩදාසියක සටහන් කරගන්න. මෙය ඉතා සාර්ථක ක්‍රමයකි.

1. Python යනු කුමක්ද?

Python යනු ඉගෙනීමට පහසු, ඉතා ජනප්‍රිය සහ ප්‍රබල (high-level) ක්‍රමලේඛන භාෂාවකි (Programming Language). එය මුලින්ම නිර්මාණය කරන ලද්දේ Guido van Rossum විසින් 1991 දීය.

Python විශේෂ වන්නේ ඇයි?
  • සරල බව: ඉංග්‍රීසි භාෂාවට සමාන සරල කේතීකරණ රටාවක් ඇත.
  • බහුකාර්ය: Web Development, AI/Machine Learning, Data Science වැනි විවිධ ක්ෂේත්‍ර සඳහා භාවිතා කළ හැක.

ඔබේ පළමු Python වැඩසටහන

# තිරය මත යමක් මුද්‍රණය කිරීම සඳහා print() ශ්‍රිතය භාවිතා වේ
print("Hello, World!")
print("Python ඉතා පහසුයි!")

2. විචල්‍යයන් සහ දත්ත වර්ග

පරිගණක මතකයේ දත්ත ගබඩා කරන භාජන විචල්‍යයන් (Variables) වේ. Python හි දත්ත වර්ගය ස්වයංක්‍රීයව තීරණය වේ.

age = 25          # int (පූර්ණ සංඛ්‍යා)
price = 10.50     # float (දශම)
name = "නිමල්"    # str (වචන - Quotes අනිවාර්යයි)
is_pass = True    # bool (True/False කැපිටල් අකුරින් පටන් ගනී)
📝 වැදගත්: විචල්‍ය නමක් ඉලක්කමකින් ආරම්භ කළ නොහැක. (උදා: 1name = "Kamal" යනු වැරදි කේතයකි).

3. දත්ත ව්‍යුහ (Data Structures)

Lists (ලැයිස්තු)

වෙනස් කළ හැකි දත්ත එකතුවකි. කො‍ටු වරහන් [] භාවිතා වේ.

marks = [75, 80, 90]
marks.append(65)    # අගට අලුත් එකක් එකතු කිරීම
marks[0] = 78       # පළමු අගය වෙනස් කිරීම (Index ආරම්භ වන්නේ 0 න්)

Tuples (ටපල්ස්)

වෙනස් කළ නොහැකි දත්ත එකතුවකි. සාමාන්‍ය වරහන් () භාවිතා වේ.

vowels = ('a', 'e', 'i', 'o', 'u')
# vowels[0] = 'b' <-- මෙය කළ නොහැක! Error එකක් පැමිණේ.

Dictionaries (ශබ්දකෝෂ)

Key සහ Value යුගල ලෙස ගබඩා කරයි. සඟල වරහන් {} භාවිතා වේ.

student = {"name": "Amal", "age": 16}
print(student["name"]) # "Amal" ලබා දෙයි
📝 වැදගත්: "වෙනස් කළ නොහැකි" (Immutable) දත්ත ව්‍යුහය කුමක්දැයි ඇසුවහොත් පිළිතුර Tuple වේ.

4. ශ්‍රිත (Functions)

නැවත නැවත භාවිතා කළ හැකි කේත කාණ්ඩයකි. ආරම්භ කරන්නේ def යන වචනයෙනි.

# ශ්‍රිතය නිර්මාණය (Definition)
def calculate_total(maths, science):
    total = maths + science
    return total

# ශ්‍රිතය ඇමතීම (Calling)
my_marks = calculate_total(85, 90)
print(my_marks) # 175
📝 වැදගත්: Function එකක් තුළ ඇති විචල්‍යයන් (උදා: ඉහත total) පිටතින් භාවිතා කළ නොහැක (Local Scope). අගයක් පිටතට ගැනීමට return භාවිතා කළ යුතුය.

5. ලූපය (Loops - For & While)

For Loop

නිශ්චිත වාර ගණනක් හෝ List එකක ඇති අයිතම ගණනට සමානව කේතය ධාවනය කිරීමට.

# 0 සිට 4 දක්වා මුද්‍රණය කිරීම
for i in range(5):
    print(i)

While Loop

කොන්දේසියක් සත්‍ය (True) වන තාක් කල් කේතය ධාවනය කිරීමට.

x = 1
while x <= 3:
    print("Python")
    x = x + 1  # මෙය අමතක කළහොත් Infinite Loop එකක් (නොනවතින ලූපයක්) හැදේ.

6. ගොනු හැසිරවීම (File Handling)

වැඩසටහනක් අවසන් වූ පසු එහි ඇති දත්ත (Variables) මතකයෙන් මැකී යයි. දත්ත ස්ථිරවම (permanently) ගබඩා කර තබාගැනීමට Text files භාවිතා කිරීම File Handling මගින් සිදු කෙරේ.

ප්‍රධාන ගොනු විවෘත කිරීමේ ක්‍රම (Modes):
  • "r" - Read (කියවීම): දත්ත කියවීමට පමණි. ගොනුව නොමැති නම් Error එකක් පැමිණේ.
  • "w" - Write (ලිවීම): ලිවීමට පමණි. ගොනුවේ පැරණි දත්ත සියල්ල මැකී නව දත්ත ලියවේ. ගොනුවක් නොමැති නම් අලුතින් සාදයි.
  • "a" - Append (එකතු කිරීම): පැරණි දත්ත නොමැකී, අලුත් දත්ත ගොනුවේ අගට එකතු වේ.

1. ආරක්ෂිතම ක්‍රමය (The 'with' statement) 🌟

සාමාන්‍යයෙන් ගොනුවක් open() කළ පසු අනිවාර්යයෙන්ම close() කළ යුතුය. නමුත් with භාවිතා කළ විට එය ස්වයංක්‍රීයවම වැසී යයි (Auto-close). කේත ලිවීමේදී (සහ විභාගවලදී) මෙය භාවිතා කිරීම ඉතා හොඳ පුරුද්දකි.

# ගොනුවට ලිවීම (Write)
with open("data.txt", "w") as file:
    file.write("Hello Python!\n")
    file.write("මෙය දෙවන පේළියයි.")
# මෙහි file.close() ලිවීම අවශ්‍ය නොවේ. එය ස්වයංක්‍රීයයි!

2. ගොනුවක් කියවීම (Reading Data)

ගොනුවක ඇති දත්ත කියවීමට ප්‍රධාන ක්‍රම 3ක් ඇත:

with open("data.txt", "r") as file:
    # 1. read() - සම්පූර්ණ ගොනුවම එකවර කියවීම (String එකක් ලෙස)
    content = file.read()
    
    # 2. readline() - එක් පේළියක් පමණක් කියවීම
