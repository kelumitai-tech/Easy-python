Python ක්‍රමලේඛනය මුල සිට සරලව

Theory පමණක් නොව, ප්‍රායෝගිකව (Practical) කේතීකරණය ඉගෙන ගන්න. නවීන තාක්ෂණය සහ අන්තර්ක්‍රියාකාරී මෙවලම් සමඟින් ඔබේ Programming සිහිනය සැබෑ කරගන්න.

ප්‍රායෝගික ඉගෙනුම

Data Science, Web Development සහ AI ඇතුළු ලොව ඉහළම වැටුප් සහිත ක්ෂේත්‍ර සඳහා Python යනු ප්‍රධානතම භාෂාවයි.

🎯

සරල සහ පැහැදිලි

ඉංග්‍රීසි භාෂාවට සමාන සරල කේත රටාවක් ඇති බැවින්, ආරම්භකයින්ට ඉගෙනීමට ඇති හොඳම භාෂාවයි.

💡 ස්මාර්ට් කේතීකරණ රහස් (Smart Coding Tricks)

පයිතන් කේතීකරණයේදී ඔබව ප්‍රවීණයෙකු (Expert) කරන සුවිශේෂී රහස් කිහිපයක් පහත දැක්වේ:

🚀 Secret 1: කෝලන් (:) සහ Indentation
ඔබේ කේතයේ If, For, While, Def වැනි පාලන ව්‍යුහයන් (Control Structures) ලියන සෑම විටම පේළිය අවසානයේ : යෙදීමට අමතක නොකරන්න. ඉන්පසු එන පේළිය අනිවාර්යයෙන්ම හිස්තැන් (Space/Tab) තබා ආරම්භ කළ යුතුය.
🚀 Secret 2: දත්ත ව්‍යුහ ක්ෂණිකව හඳුනාගැනීම
වරහන් වර්ගය දුටු පමණින් දත්ත ව්‍යුහය හඳුනාගන්න:
  • [ ] කො‍ටු වරහන් = List (ඕනෑම විටක වෙනස් කළ හැක)
  • ( ) සාමාන්‍ය වරහන් = Tuple (වරක් හැදූ පසු වෙනස් කළ නොහැක)
  • { } සඟල වරහන් = Dictionary (Key-Value යුගල ලෙස ගබඩා වේ)
🚀 Secret 3: මනසින් කේතය ධාවනය කිරීම (Dry Run)
ඔබේ කේතයේ දෝෂයක් (Bug) ඇතිවිට, පරිගණකයක් මෙන් සිතා පේළියෙන් පේළිය කේතය කියවන්න. විචල්‍යයක අගය වෙනස් වන සෑම අවස්ථාවක්ම කඩදාසියක සටහන් කරගන්න. මෙය ඉතා සාර්ථක ක්‍රමයකි.
🚀 Secret 4: Case Sensitivity (අකුරු වල ප්‍රමාණය)
Python යනු Case-Sensitive භාෂාවකි. එනම් කැපිටල් (Capital) සහ සිම්පල් (Simple) අකුරු එකිනෙකට වෙනස් ලෙස සලකයි. උදාහරණයක් ලෙස Age සහ age යනු විචල්‍යයන් (variables) දෙකකි. Print කිරීමේදී Print() ලෙස කැපිටල් අකුරින් ලිවීමෙන් Error එකක් පැමිණේ. සෑමවිටම නිවැරදි අකුරු ප්‍රමාණය භාවිතා කරන්න.

Python හැඳින්වීම (Introduction)

Python යනු ලොව පුරා ඉතා ජනප්‍රිය ක්‍රමලේඛන භාෂාවකි. එය 1991 දී Guido van Rossum විසින් නිර්මාණය කරන ලදී.

Python භාවිතා කරන්නේ කුමක් සඳහාද?

  • Web Development (Server-side) - වෙබ් අඩවි නිර්මාණය
  • Software Development - මෘදුකාංග සංවර්ධනය
  • Mathematics & Data Science - දත්ත විශ්ලේෂණය සහ AI
  • System Scripting - පද්ධති ස්වයංක්‍රීයකරණය

Example

print("Hello, World!")

💡 දැනුම පරීක්ෂාව

ප්‍රශ්නය: Python කේතයක් තිරයේ මුද්‍රණය කිරීමට භාවිතා කරන ශ්‍රිතය (function) කුමක්ද?

පිළිතුර බලන්න

පිළිතුර: print()

Python වාක්‍ය වින්‍යාසය (Syntax)

Python හි Syntax එක ඉංග්‍රීසි භාෂාවට ඉතා සමාන වන අතර එය කියවීමට ඉතා පහසුය.

Python Indentation (හිස්තැන් තැබීම)

වෙනත් භාෂාවන්හිදී (C++, Java) කේත කොටසක් වෙන් කිරීමට සඟල වරහන් {} භාවිතා කළද, Python හි ඒ සඳහා Indentation (හිස්තැන්) භාවිතා කරයි. මෙය ඉතා වැදගත් වේ.

නිවැරදි භාවිතය:

if 5 > 2:
    print("පහ දෙකට වඩා විශාලයි!") # මෙහි හිස්තැන් තැබීම අනිවාර්යයි
දෝෂයක් (Syntax Error): හිස්තැන් නොතැබුවහොත් Python විසින් Error එකක් ලබාදේ.

💡 දැනුම පරීක්ෂාව

ප්‍රශ්නය: Python හි කේත කොටසක් වෙන් කිරීමට භාවිතා කරන්නේ කුමක්ද?

පිළිතුර බලන්න

පිළිතුර: Indentation (හිස්තැන් තැබීම)

Python සටහන් (Comments)

ඔබ ලියන කේතය (code) පැහැදිලි කිරීමට හෝ තාවකාලිකව කේතයක් අක්‍රීය කිරීමට Comments භාවිතා කළ හැක.

Creating a Comment

Comment එකක් # ලකුණෙන් ආරම්භ වේ. Python විසින් මෙය කියවන්නේ නැත.

# මෙය Comment එකකි
print("Hello, World!") # මෙයද කේතයට බාධාවක් නොවේ

💡 දැනුම පරීක්ෂාව

ප්‍රශ්නය: Python හි Single-line comment එකක් ලියන සංකේතය කුමක්ද?

පිළිතුර බලන්න

පිළිතුර: # ලකුණ

Python විචල්‍යයන් (Variables)

විචල්‍යයන් යනු දත්ත ගබඩා කර තබා ගන්නා භාජන (Containers) වේ.

Creating Variables

Python වලදී විචල්‍යයක් සෑදීමට විශේෂ විධානයක් අවශ්‍ය නොවේ. අගයක් ලබා දුන් වහාම එය සෑදේ.

x = 5
y = "කමල්"
print(x)
print(y)

Variable Names (නම් කිරීමේ නීති)

  • අකුරකින් හෝ යටි ඉරකින් (_) ආරම්භ විය යුතුය.
  • ඉලක්කමකින් ආරම්භ කළ නොහැක.
  • Case-sensitive වේ (age, Age යනු දෙකකි).

💡 දැනුම පරීක්ෂාව

ප්‍රශ්නය: වයස 20 ලෙස ගබඩා කිරීමට විචල්‍යයක් (Variable) සාදන්නේ කෙසේද?

පිළිතුර බලන්න

පිළිතුර: age = 20

Python දත්ත වර්ග (Data Types)

Python වල බහුලව භාවිතා වන දත්ත වර්ග කිහිපයක් ඇත.

දත්ත වර්ගයඋදාහරණ
Text Typestr (String) - "Hello"
Numeric Typesint (10), float (10.5)
Sequence Typeslist ([1, 2]), tuple ((1, 2))
Mapping Typedict ({"name": "Amal"})
Set Typesset ({1, 2, 3})
Boolean Typebool (True / False)

දත්ත වර්ගය බැලීම (Getting the Data Type)

x = 5
print(type(x)) # Output: <class 'int'>

💡 දැනුම පරීක්ෂාව

ප්‍රශ්නය: x = 10.5 හි දත්ත වර්ගය (Data type) කුමක්ද?

පිළිතුර බලන්න

පිළිතුර: float

Python Numbers & Casting

ප්‍රධාන සංඛ්‍යා වර්ග 2ක් ඇත: Integer සහ Float.

Numbers

x = 10      # int
y = 3.14    # float
z = -5      # int

Type Casting (එක් වර්ගයකින් තවත් වර්ගයකට හැරවීම)

දත්තයක වර්ගය අපට අවශ්‍ය පරිදි වෙනස් කරගැනීමට int(), float(), str() භාවිතා කරයි.

x = int(2.8)    # x හි අගය 2 වේ
y = float("3")  # y හි අගය 3.0 වේ
z = str(10)     # z හි අගය වචනයක් ලෙස "10" වේ

💡 දැනුම පරීක්ෂාව

ප්‍රශ්නය: දශම සංඛ්‍යාවක් (Float) පූර්ණ සංඛ්‍යාවක් (Integer) බවට පත් කරන්නේ කුමන ශ්‍රිතයෙන්ද?

පිළිතුර බලන්න

පිළිතුර: int()

Python Strings

Strings යනු අකුරු හෝ වචන වේ. ඒවා තනි උද්ධෘත (' ') හෝ ද්විත්ව උද්ධෘත (" ") තුළ ලිවිය හැක.

String Methods

a = "Hello, World!"
print(len(a))      # අකුරු ගණන සෙවීමට (Length)
print(a.upper())   # සියල්ල කැපිටල් කිරීමට
print(a.lower())   # සියල්ල සිම්පල් කිරීමට
print(a.replace("H", "J")) # අකුරක් මාරු කිරීමට (Jello, World!)
String Concatenation: වචන දෙකක් එකතු කිරීමට + ලකුණ භාවිතා කරයි. (උදා: "A" + "B" = "AB")

💡 දැනුම පරීක්ෂාව

ප්‍රශ්නය: "Hello" යන වචනයේ අකුරු ගණන සොයන්නේ කෙසේද?

පිළිතුර බලන්න

පිළිතුර: len("Hello")

Python Booleans

Programming වලදී බොහෝ විට සත්‍ය ද අසත්‍ය ද යන්න දැනගැනීමට අවශ්‍ය වේ. Boolean මගින් ලබා දෙන්නේ True හෝ False අගයන් දෙකෙන් එකකි.

Boolean Values

print(10 > 9)  # True
print(10 == 9) # False
print(10 < 9)  # False

💡 දැනුම පරීක්ෂාව

ප්‍රශ්නය: 10 > 15 හි ප්‍රතිඵලය කුමක්ද?

පිළිතුර බලන්න

පිළිතුර: False

Python Operators

විචල්‍යයන් හා අගයන් මත විවිධ මෙහෙයුම් සිදු කිරීමට Operators භාවිතා කරයි.

1. Arithmetic (ගණිත කර්ම)

+   එකතු කිරීම (Addition)
-   අඩු කිරීම (Subtraction)
*   ගුණ කිරීම (Multiplication)
/   බෙදීම (Division)
%   බෙදූ පසු ඉතිරිය (Modulus)
**  බෙදූ පසු පූර්ණ සංඛ්‍යාව (Floor division)

2. Comparison (සැසඳීම)

==  සමානයි
!=  අසමානයි
>   විශාලයි
<   කුඩායි
>=  විශාලයි හෝ සමානයි

3. Logical (තාර්කික)

and  - කොන්දේසි දෙකම සත්‍ය නම් True වේ
or   - එක් කොන්දේසියක් හෝ සත්‍ය නම් True වේ
not  - ප්‍රතිඵලය කණපිට හරවයි

💡 දැනුම පරීක්ෂාව

ප්‍රශ්නය: 10, 3 න් බෙදූ පසු ඉතිරිය (Modulus) සෙවීමේ කේතය ලියන්න.

පිළිතුර බලන්න

පිළිතුර: 10 % 3

Python Input (ආදාන)

පරිශීලකයාගෙන් (User) යම්කිසි දත්තයක් ලබා ගැනීමට Python හිදී input() ශ්‍රිතය භාවිතා කරයි.

Input Example

# පරිශීලකයාගෙන් නම ලබා ගැනීම
name = input("ඔබේ නම කුමක්ද? ")
# ලබාගත් නම සමඟ ආචාර කිරීම
print("ආයුබෝවන්, " + name)
වැදගත්: input() මගින් ලබාගන්නා දත්ත නිතරම String (වචන) ලෙස සලකනු ලැබේ. සංඛ්‍යාවක් ලබා ගැනීමට අවශ්‍ය නම් int() හෝ float() භාවිතා කර එය හරවා (Cast කර) ගත යුතුය.
උදා: age = int(input("වයස කීයද? "))

💻 Input ශ්‍රිතය අත්හදා බලමු (Run the Code)

මෙම කේතය ධාවනය කිරීමේදී අගයන් ලබාදීම සඳහා තිරය මැද Text Box එකක් දිස්වනු ඇත.

💻 Terminal Output

💡 දැනුම පරීක්ෂාව

ප්‍රශ්නය: input() ශ්‍රිතයෙන් ලබාගන්නා දත්ත නිතරම කුමන Data type එකකින් යුක්ත වේද?

පිළිතුර බලන්න

පිළිතුර: String (str)

Python Lists (ලැයිස්තු)

බහුවිධ දත්ත එකවර ගබඩා කිරීමට List භාවිතා කරයි. මෙය වෙනස් කළ හැක (Mutable). කො‍ටු වරහන් [] භාවිතා වේ.

List එකක් සෑදීම සහ දත්ත ලබාගැනීම

fruits = ["apple", "banana", "cherry"]
print(fruits[0])  # "apple" මුද්‍රණය වේ
# අලුතින් දත්තයක් එකතු කිරීම
fruits.append("orange")
# දත්තයක් වෙනස් කිරීම
fruits[1] = "mango"
print(fruits) # ['apple', 'mango', 'cherry', 'orange']

💡 දැනුම පරීක්ෂාව

ප්‍රශ්නය: List එකකට අලුතින් අයිතමයක් එකතු කරන method එක කුමක්ද?

පිළිතුර බලන්න

පිළිතුර: .append()

Python Tuples

Tuple යනු List එකටම සමාන, නමුත් වෙනස් කළ නොහැකි (Immutable) දත්ත සමූහයකි. සාමාන්‍ය වරහන් () භාවිතා කරයි.

Tuple Example

thistuple = ("apple", "banana", "cherry")
print(thistuple[1])
# thistuple[1] = "mango"  <-- මෙය කළ නොහැක! Error පැමිණේ.

💡 දැනුම පරීක්ෂාව

ප්‍රශ්නය: Tuple එකක දත්ත පසුව වෙනස් කළ හැකිද?

පිළිතුර බලන්න

පිළිතුර: නැත (එය Immutable වේ)

Python Sets (කුලක)

Set එකක දත්ත වලට නිශ්චිත පිළිවෙලක් නැත (Unordered). තවද එකම දත්තය දෙවරක් තිබිය නොහැක (No duplicates). සඟල වරහන් {} භාවිතා කරයි.

Set Example

myset = {"apple", "banana", "cherry", "apple"}
print(myset) 
# ප්‍රතිඵලයේ "apple" ඇත්තේ එක් වරක් පමණි!

💡 දැනුම පරීක්ෂාව

ප්‍රශ්නය: Set එකක එකම අගය (duplicate) දෙවරක් පැවතිය හැකිද?

පිළිතුර බලන්න

පිළිතුර: නැත

Python Dictionaries

Key:Value (යතුර සහ අගය) යුගල ලෙස දත්ත ගබඩා කරයි. සඟල වරහන් {} භාවිතා කරයි.

Dictionary Example

car = {
  "brand": "Ford",
  "model": "Mustang",
  "year": 1964
}
print(car["model"]) # "Mustang" ලබා දෙයි
# අගය වෙනස් කිරීම
car["year"] = 2020

💡 දැනුම පරීක්ෂාව

ප්‍රශ්නය: Dictionary එකක දත්ත ගබඩා වන ආකාරය හඳුන්වන්නේ කෙසේද?

පිළිතුර බලන්න

පිළිතුර: Key-Value (යතුර සහ අගය) යුගල ලෙස

Python If ... Else

ගණිතමය කොන්දේසි මත පදනම්ව තීරණ ගැනීම සඳහා if භාවිතා වේ.

If, Elif, Else

a = 200
b = 33
if b > a:
    print("b විශාලයි")
elif a == b:
    print("සමානයි")
else:
    print("a විශාලයි") # මෙය ක්‍රියාත්මක වේ
Indentation: if ප්‍රකාශයෙන් පසුව එන පේළි අනිවාර්යයෙන්ම හිස්තැන් තබා ලිවිය යුතුය.

💡 දැනුම පරීක්ෂාව

ප්‍රශ්නය: if කොන්දේසිය අසත්‍ය වූ විට ක්‍රියාත්මක වන කොටස කුමක්ද?

පිළිතුර බලන්න

පිළිතුර: else කොටස

Python While ලූපය

කොන්දේසියක් සත්‍ය (True) වන තාක් කල් කේත කාණ්ඩයක් නැවත නැවත ක්‍රියාත්මක කිරීමට while ලූපය භාවිතා වේ.

The while Loop

i = 1
while i < 6:
    print(i)
    i += 1  # මෙය අමතක කළහොත් ලූපය කිසිදා නතර නොවේ (Infinite loop)

💡 දැනුම පරීක්ෂාව

ප්‍රශ්නය: While loop එකක් කිසිදා නතර නොවන තත්ත්වයක් හැඳින්වෙන්නේ කෙසේද?

පිළිතුර බලන්න

Python For ලූපය

List, Tuple, Dictionary හෝ String එකක අයිතම එකින් එක ගෙන ක්‍රියාත්මක කිරීම සඳහා for ලූපය භාවිතා වේ.

List එකක් හරහා යාම

fruits = ["apple", "banana", "cherry"]
for x in fruits:
    print(x)

The range() Function

නිශ්චිත වාර ගණනක් ලූපය ධාවනය කිරීමට.

for x in range(5):
    print(x) # 0 සිට 4 දක්වා මුද්‍රණය වේ

💡 දැනුම පරීක්ෂාව

ප්‍රශ්නය: for x in range(3): මගින් කී වතාවක් ලූපය ක්‍රියාත්මක වේද?

පිළිතුර බලන්න

පිළිතුර: 3 වතාවක් (0, 1, 2)

Python Break Statement

Loop එකක් (While හෝ For) සම්පූර්ණයෙන්ම අවසන් වීමට පෙර, යම් නිශ්චිත කොන්දේසියකදී එය අතරමගින් නතර කිරීමට (Stop) break භාවිතා කරයි. මෙහි වැදගත්කම වන්නේ අනවශ්‍ය ලෙස ලූපය ධාවනය වීම වළක්වා කාලය සහ මතකය (Memory) ඉතිරි කිරීමයි.

Example: While Loop එකකදී

i = 1
while i < 10:
    print(i)
    if i == 3:
        break # i සමාන 3 වූ විට ලූපය නතර වේ
    i += 1

💡 දැනුම පරීක්ෂාව

ප්‍රශ්නය: break මූල පදය භාවිතා කරන්නේ කුමක් සඳහාද?

පිළිතුර බලන්න

පිළිතුර: ක්‍රියාත්මක වන ලූපයක් (Loop) අතරමගින් නතර කිරීමට.

Python Continue Statement

Loop එකක් (While හෝ For) ක්‍රියාත්මක වන විට, සම්පූර්ණ ලූපයම නතර නොකර යම් නිශ්චිත අවස්ථාවක් (iteration) පමණක් මඟ හැර (Skip කර) ඊළඟ වාරයට කෙලින්ම ගමන් කිරීමට continue මූල පදය භාවිතා කරයි.

Example: For Loop එකකදී

for i in range(1, 6):
    if i == 3:
        continue # i සමාන 3 වූ විට මුද්‍රණය නොකර ඊළඟ අංකයට යයි
    print(i)
# ප්‍රතිඵලය:
# 1
# 2
# 4
# 5

💡 දැනුම පරීක්ෂාව

ප්‍රශ්නය: ලූපයක් සම්පූර්ණයෙන්ම නතර නොකර, එහි එක් පියවරක් පමණක් මඟ හැරීමට (Skip) භාවිතා කරන මූල පදය කුමක්ද?

පිළිතුර බලන්න

පිළිතුර: continue

Python Functions (ශ්‍රිත)

ශ්‍රිතයක් යනු අවශ්‍ය වූ විට පමණක් ක්‍රියාත්මක කළ හැකි කේත කාණ්ඩයකි. ශ්‍රිතයක් ආරම්භ කරන්නේ def මූල පදයෙනි.

Creating and Calling a Function

# ශ්‍රිතය සෑදීම
def my_function(name):
    print("Hello " + name)
# ශ්‍රිතය ඇමතීම
my_function("Kamal")
my_function("Amal")

Return Values

අගයක් ආපසු ලබා දීමට return භාවිතා කරන්න.

def add(x, y):
    return x + y
print(add(5, 3)) # 8 ලබා දෙයි

💡 දැනුම පරීක්ෂාව

ප්‍රශ්නය: ශ්‍රිතයක් (Function) නිර්මාණය කිරීමට භාවිතා කරන keyword එක කුමක්ද?

පිළිතුර බලන්න

පිළිතුර: def

Python Classes and Objects

Python යනු Object-Oriented භාෂාවකි. මෝස්තරයක් (Blueprint) සෑදීමට Class එකක් භාවිතා කරයි.

Class එකක් සෑදීම (The __init__() Function)

class Person:
    def __init__(self, name, age):
        self.name = name
        self.age = age
# Object එකක් සෑදීම
p1 = Person("John", 36)
print(p1.name)
print(p1.age)
Note: __init__ ශ්‍රිතය සෑම විටම පන්තියකින් Object එකක් සාදන විට ස්වයංක්‍රීයව ක්‍රියාත්මක වේ.

💡 දැනුම පරීක්ෂාව

ප්‍රශ්නය: Class එකකින් Object එකක් සාදන විට ස්වයංක්‍රීයව ක්‍රියාත්මක වන ශ්‍රිතය කුමක්ද?

පිළිතුර බලන්න

පිළිතුර: __init__()

Python Try ... Except

කේතයේ දෝෂ (Errors) හටගත් විට වැඩසටහන නතර නොවී පවත්වා ගැනීමට මෙය භාවිතා කරයි.

Exception Handling

try:
    # ගැටළුවක් ඇතිවිය හැකි කේතය
    print(x) # x නිර්මාණය කර නොමැත
except:
    # දෝෂයක් ඇතිවූ විට සිදුවිය යුතු දේ
    print("විචල්‍යය නිර්මාණය කර නොමැත!")
finally:
    # කුමක් සිදු වුවත් මෙය ක්‍රියාත්මක වේ
    print("Try-except ක්‍රියාවලිය අවසන්.")

💡 දැනුම පරීක්ෂාව

ප්‍රශ්නය: Error එකක් ඇතිවූ විට වැඩසටහන නතර නොවී ක්‍රියාත්මක වීමට දමන කොටස කුමක්ද?

පිළිතුර බලන්න

පිළිතුර: except කොටස

Python File Handling

ගොනු (files) කියවීම, ලිවීම සහ නිර්මාණය කිරීම සඳහා open() ශ්‍රිතය භාවිතා වේ.

ප්‍රධාන ගොනු විවෘත කිරීමේ ක්‍රම (Modes):
  • "r" - Read (කියවීම): දත්ත කියවීමට පමණි. ගොනුව නොමැති නම් Error පැමිණේ.
  • "w" - Write (ලිවීම): පැරණි දත්ත මැකී නව දත්ත ලියවේ. ගොනුවක් නොමැති නම් සාදයි.
  • "a" - Append (එකතු කිරීම): පැරණි දත්ත නොමැකී අගට එකතු වේ.

Writing to a File (The 'with' statement)

with භාවිතා කළ විට ගොනුව ස්වයංක්‍රීයව close වේ.

with open("demofile.txt", "w") as file:
    file.write("මෙය නව දත්තයකි!")

Reading from a File

with open("demofile.txt", "r") as file:
    print(file.read())
📝 විභාග සටහන: read() මගින් සම්පූර්ණ ගොනුව String එකක් ලෙසත්, readlines() මගින් එය List එකක් ලෙසත් ලබාදෙයි.

💡 දැනුම පරීක්ෂාව

ප්‍රශ්නය: පැරණි දත්ත නොමැකී ෆයිල් එකකට අලුත් දත්ත ලිවීමට භාවිතා කරන mode එක කුමක්ද?

පිළිතුර බලන්න

පිළිතුර: "a" (Append Mode)

Python Numpy (දත්ත විද්‍යාව)

Numpy (Numerical Python) යනු ගණිතමය ගණනය කිරීම් සහ දත්ත විශ්ලේෂණය (Data Science) සඳහා භාවිතා කරන ඉතා ප්‍රබල Library එකකි. සාමාන්‍ය Python Lists වලට වඩා මෙය 50x ගුණයක් දක්වා වේගවත්ය.

Numpy Array එකක් සෑදීම

import numpy as np
# 1D Array එකක් සෑදීම
arr = np.array([1, 2, 3, 4, 5])
print(arr)

Python Matplotlib (ප්‍රස්ථාර)

Matplotlib යනු දත්ත ප්‍රස්ථාර (Graphs & Charts) ලෙස දෘශ්‍යමාන (Visualize) කිරීමට භාවිතා කරන ජනප්‍රියම Library එකයි.

සරල රේඛා ප්‍රස්ථාරයක් (Line Chart)

import matplotlib.pyplot as plt
import numpy as np
x = np.array([1, 2, 3, 4])
y = np.array([10, 20, 25, 30])
plt.plot(x, y) # රේඛාව ඇඳීම
plt.show() # ප්‍රස්ථාරය පෙන්වීම
